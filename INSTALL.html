nanoPrint — Install

Lean OctoPrint fork, N printers on one host. This page covers the recommended one-command path — see INSTALL_RPi3.md for the full manual walkthrough and troubleshooting.

1Prerequisites

  • Raspberry Pi 3B/3B+ (or better — see hardware note below)
  • Raspberry Pi OS Lite (64-bit) — Bookworm or Bullseye
  • microSD 16GB+, Class 10 / A1
  • SSH access to the Pi

Flash via Raspberry Pi Imager, set hostname (e.g. raspberrypi), enable SSH, then:

ssh pi@raspberrypi.local
sudo apt update && sudo apt upgrade -y

2Get the source and run the installer

git clone <repo-url> ~/nanoprint-src && cd ~/nanoprint-src
./install.sh

One command sets up system tuning, both printer instances, nginx, and the dashboard. Safe to re-run — it never overwrites an existing config.yaml.

More than 2 printers on this host? Set PRINTER_COUNT before running: 
PRINTER_COUNT=4 ./install.sh
RPi3 hardware note: the lean tuning this installer applies was only validated with 2 concurrent instances on RPi3-class hardware (1GB RAM, 4-core burst). Going higher on the same board is untested — watch htop during a real print before trusting more instances unattended. A more capable board (RPi4/5) has real headroom for a bigger "mini farm."

3What you get

  • Printer 1 UIhttp://raspberrypi.local/
  • Printer 2 UIhttp://raspberrypi.local:5001
  • Dashboardhttp://raspberrypi.local/dashboard/

First visit to each printer UI shows the OctoPrint setup wizard — connect each instance to its own USB serial port there.

You were added to the dialout group during install — log out and back in (or reboot) before serial ports work.

4Adding printers beyond the first two

Open the dashboard and click + Add Printer for each instance you set up with PRINTER_COUNT — it defaults to the next sequential port (raspberrypi.local:5002, :5003, ...) automatically, matching what the installer just set up.
